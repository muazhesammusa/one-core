# SEO Rules

## Priority Order
1. Search intent
2. Title optimization
3. Meta description
4. Internal linking
5. Structured data
6. Readability

## Content Rules
- Use natural language
- Avoid keyword stuffing
- Prefer short paragraphs
- Use headings (H2/H3)
- Answer-first structure

## Internal Linking
- Max 3–5 links per page
- Use relevant anchor text
- Prefer high-authority pages

## Schema
Recommend:
- Article
- FAQPage
- HowTo

## GEO / AEO
- Direct answers first
- Use FAQ format when useful
- Focus on entities and facts
