# 🏗 CloudFold Architecture

## Layers
1. Core (Plugin Loader, Activator)
2. Admin (React App)
3. Frontend (Rendering Engine)
4. API (REST / AJAX)

## Design Pattern
- Feature-based modules
- Service layer for logic
- Separate UI and logic

## Naming Convention
- PHP: cloudfold_*
- JS: camelCase
- CSS: pix-

## File Strategy
- One responsibility per file
- No large monolithic files
